- Bench version: `0.2.0` | seed: `42` | trials per tier: `8` | MuJoCo `4.0.1` | Python `3.13.18`
- code SHA-256: `a3b634dc8bf05403afbff4118f3b8173e622b882aaa7856ddbea32dbae7d03fd`
- model SHA-256: `128414ba9f0481088f8f9f59c9912fdc3d7916d54b0c02c915937ab2ad5d372f`
- runs SHA-256: `ede1f509e3d7da9a3871b5aaa34eabdad660c541962c0b1b2767077ba60fadfb`
- Verdict rule: **FAIL** if any non-foot geom touches the floor or the pelvis drops below 0.45 m within 5.0 s of fault onset; else PASS.

- Stance leg = right (fixed before any baseline run): F3 derates the right knee hardest, and the loaded knee is the one that heats up.
- Post-fault horizon is 5.0 s (v0.1 uses 3 s); the 'Falls after 3 s' column shows which falls a 3 s horizon would have missed.
- Push tier upper bound (35 N) was set from the no-fault control alone (it survives 40 N x 0.15 s in all 8 tested directions, fails at 60 N toward the swing side).
- realistic_brake_all_joints is a diagnostic ablation, not a baseline: same delay and finite holding torque, every joint braked.
